Authority, settlement state and Notable Locations.

- **Size** now has its finalised 1d10 distribution: Trading Post, Village, Town, City and Capital.
- New **Economy** stage (Failing to Wealthy).
- New **Authority** stage, with **Representation** and **Authority Size** where they apply (a single ruler or a group of representatives).
- **Roles**: each Authority Figure gets a role from its Authority's own tables. A lead is rolled first, and unique roles are never handed out twice.
- **Authority Figures**: generated NPCs with species, gender, age, disposition, motive, reputation, flaw and relationships between them. Names are rolled from species-specific naming tables (Human, the Elves, Dwarf, Dragonborn, the Genasi, Firbolg and Yuan-ti). Every detail can be re-rolled, chosen or typed.
- New **Security**, **Crime** and **Stability** stages, each an ordered 1d12 scale.
- New **Notable Locations** stage:
  - the number of locations depends on the Size;
  - Cities (2–4 districts) and Capitals (3–5 districts) roll a count for each district;
  - each location rolls its type on a 1d20: Hospitality, Trade / Shop, Craft / Workshop, Religious, Civic / Government, Military / Security, Guild / Organisation, Knowledge / Education, Entertainment, Criminal, Industry / Resource or Unusual / Special;
  - in Manual generation, district counts, location counts and types can each be re-rolled or chosen.
- New setting, **Bare Minimum Buildings**: every settlement gets one extra Notable Location, a Tavern with 4 spare rooms. It is added on top of the rolled locations, once per settlement, never per district.
- Every new table can be customised in Settings → View Tables. Tag View shows how each result was reached.
- Settlements saved with v0.1.1 open unchanged. Stages added since then show as not recorded until you roll them.

Planned influences between tables (for example Purpose favouring certain location types) are recorded for future use but do not change any rolls yet. Location subtypes, location details, NPCs and noble estates are still to come.
