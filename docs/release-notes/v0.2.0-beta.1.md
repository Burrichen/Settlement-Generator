**Beta: the no-code generator framework.** A test build for trying out the new editors. It is not offered as an automatic update, and is not meant for everyday use yet.

> **Before you install:**
>
> - This beta is built from v0.1.5 and does **not** include maps. If you have installed the **maps beta (v0.1.6-beta.1)**, this beta cannot open the data it upgraded, and will say so without changing anything. To try this beta, restore the `pre-migration-…-schema1-to-schema5` backup (in the `backups` folder beside your data), or test on another Windows account.
> - Data from v0.1.5 opens unchanged: settings, saved settlements, favourites, and your table and tag edits are all kept. Edits made with this beta's new editors have not been tested in v0.1.5, so back up your data first if you plan to go back.

- **Generation is now a flow** you can see and change: the Settlement Pipeline is a list of steps (roll a table, conditions, repeat, run another flow), and Authority Figures and Notable Locations are built-in steps. Generation results are the same as v0.1.5 for the same dice.
- **Table Editor:** create and edit tables without JSON. Results, dice and chances, rerolls, follow-up rolls, modifiers, Shift and Cap, and layouts that match the chances you want.
- **Flow Editor:** build and rearrange flows with steps, conditions and branches, with problems shown as you go.
- **Tags, Settings and Modifiers editors:** settings come in kinds (on/off, number, choice, multiple choice, text), Bare Minimum Buildings is now an ordinary setting, and every modifier is explained in plain English. A modifier can be Active or Planned (shown and documented, but not yet run).
- **Test any table or flow:** Roll once, Step through, or Run 100 / 1,000 / 10,000. It shows how often each result came up next to the chance the dice should give, results that can never happen, branches that never run, which modifiers were used, and any errors. Tests use software dice and save nothing.
- **Roll details (advanced):** turn it on in Settings to see how every value was reached: base roll, each modifier and where it came from, final roll, and any shifts.
- **Import / Export** (Settings): share tables, tags, settings, flows or a whole content pack as a file. Imports are checked before anything changes, and you choose what happens when an ID is already used: keep both, replace yours, or keep yours.
- **Safe deleting:** every item shows what uses it, each use opens the item that depends on it, and nothing that is still in use can be deleted.
- The terminal version has all of the above.

Known limitations in this beta:

- Shared results, scales and object types have no editor yet.
- Cap at Highest/Lowest moves a result to the highest/lowest usable result on the scale; this may change.
- Testing the whole pipeline picks random settings, so many runs reach regions whose Environment tables are not written yet and show errors.
- 10,000 whole-pipeline runs take a few seconds; the terminal version waits until they finish.
- This installer is not signed for automatic updates. When the stable version is released, this beta will be offered it as a normal update.
