First release of Settlement Generator.

- Generate tabletop settlements stage by stage (Setting Profile, Region, Environment, Connections, Size, Origin, Purpose, Age) with real dice: Automatic, Manual Incremental and Manual One-table modes.
- Save settlements as snapshots; view, edit, favourite and delete them.
- Customise every table and tag (names, dice, results, effects), with live validation and reset to defaults.
- Modern Dark and Old-Timey Dark themes; God Mode and Tag View.
- Desktop app plus a full keyboard terminal app (settlement-generator-cli.exe), sharing the same data.
- Signed automatic updates, with your data backed up before every update.

Known limitations: the Size distribution and non-Kurovia Environments are not specified yet, so generation asks you to choose those. Windows may show a SmartScreen warning on first install because the installer is not code-signed.
