# Naming backlog

Which name sets have been revamped into full packs and which have not. Update
this when a pack is installed. Counts are table entries (names or name parts)
across the set's files.

## Settlement names (`content/kurovia/naming/`)

| Region      | State        | Notes                                                                                   |
| ----------- | ------------ | --------------------------------------------------------------------------------------- |
| Ordon       | Revamped     | Quality Pass v2; see [ORDON_NAMING.md](ORDON_NAMING.md)                                 |
| Bratislor   | Revamped     | 11 tables: geographic, founder, occupation, borderland and haze methods                 |
| Halingo     | Revamped     | 16 tables, 9 methods. **Heresy** is reserved and never generated                        |
| Hjartheland | Revamped     | 16 tables: mountain, winter, water, forest, shelter and inherited-name methods          |
| Nareth      | Revamped     | 20 tables: river, forest, wetland, settlement, trail, stone, elemental and inherited    |
| Shinkira    | **Not yet**  | Still two methods (geographic, founder), 5 tables, ~140 entries. Lists were enlarged only |
| Targoth     | **Not yet**  | Still two methods (geographic, founder), 5 tables, ~70 entries. Lists were enlarged only  |
| Skgurr      | **Not yet**  | One method (Geographic Compound), 2 × d100 lists of 30                                   |

## Personal names (`content/people/naming/`)

| Species      | State       | Notes                                                                                        |
| ------------ | ----------- | -------------------------------------------------------------------------------------------- |
| Human        | Revamped, one gap | Masculine, feminine and family have culture sub-pools. **Neutral given names are still one 100-name list with no culture pools** |
| Air Genasi   | Revamped    | Gendered given names and family names, with sub-pools                                        |
| Dark Elf     | Revamped    | Gendered given names and family names, with sub-pools                                        |
| Dragonborn   | Revamped    | Gendered given names and family names, with sub-pools                                        |
| Dwarf        | Revamped    | Gendered given names and family names, with sub-pools                                        |
| Earth Genasi | Revamped    | Gendered given names and family names, with sub-pools                                        |
| Eladrin      | Revamped    | Deliberately ungendered: every gender uses the neutral pools                                  |
| High Elf     | **Not yet** | d4 method, four d20 lists (~80 entries)                                                      |
| Wood Elf     | **Not yet** | d4 method, four d20 lists (~80 entries)                                                      |
| Fire Genasi  | **Not yet** | One scheme for every gender: d100 given (50) + d20 byname (20)                               |
| Yuan-ti      | **Not yet** | One scheme for every gender: d100 given (50) + d20 byname (20)                               |
| Firbolg      | **Not yet** | One scheme for every gender: one d100 list (50)                                              |
| Water Genasi | **Not yet** | One scheme for every gender: one d100 list (50)                                              |

Species with no name tables at all (for example user-added species) show
"No name table configured" rather than borrowing another species' names.

## Other settings

Only Kurovia has settlement naming. Other Setting Profiles skip the Name
stage until a scheme exists for them.
